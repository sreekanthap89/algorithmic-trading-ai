================================================================================

  Target file: models.py  (or new simulation.py)

  --- Step 4: Enhance Monte Carlo ---
  - Upgrade run_monte_carlo() to Heston stochastic volatility:

      dS = mu * S * dt  +  sqrt(V) * S * dW_S
      dV = kappa * (theta - V) * dt  +  xi * sqrt(V) * dW_V

      Parameters:
        kappa = mean reversion speed of variance
        theta = long-run variance
        xi    = volatility of volatility
        rho   = correlation between dW_S and dW_V

  - Increase default simulation paths to 10,000
    (100,000 paths is CPU-heavy without GPU acceleration)
  - Add compute_tp_sl_probability(paths, entry, take_profit, stop_loss):
      Count % of paths that hit take_profit before stop_loss

  --- Step 5: Real Markov Transition Matrix ---
  - Replace the simple momentum counter in get_markov_regime() with a
    proper 3-state transition matrix:
      State 0: Bull Trend
      State 1: Bear Trend
      State 2: Choppy / Range

  - Build transition matrix from rolling return quantiles:
      P[i][j] = probability of moving from state i to state j

  - Output: transition probabilities + current state (not just a label)
  - Use hmmlearn library or implement manual Baum-Welch EM algorithm


================================================================================
  PHASE 3: BUILD MISSING SIGNAL ENGINES  (Steps 6-7)
================================================================================

  New file: alpha_engine.py

  --- Step 6: Multi-Alpha Composite Engine ---

  4 independent alpha signals:

    Alpha 1 - Trend Momentum (weight 0.30):
      MACD crossover + SMA-20 / SMA-50 alignment
      Signal = +1 if MACD > Signal AND price > SMA-20 > SMA-50

    Alpha 2 - Mean Reversion (weight 0.20):
      Z-score of (Close - VWAP) / ATR
      Signal = +1 if zscore < -1.5 (price below VWAP, expect reversion up)

    Alpha 3 - Volume Spike (weight 0.30):
      Signal = +1 if Volume > 2x 20-bar rolling average AND price up

    Alpha 4 - Relative Strength (weight 0.20):
      RSI vs. sector median RSI
      Signal = +1 if asset RSI > sector_median_rsi + 5

  Composite conviction = weighted_average(alpha_1..4)

  Gate: requires_n_confirms = 2
    Only generate trade signal if >= 2 of 4 alphas agree

  --- Step 7: Dynamic Stop-Loss & Microstructure ---
  - Add compute_bid_ask_imbalance(df):
      Proxy = (High - Close) / ATR  (synthetic order book pressure)
      High value = selling pressure at ask
      Low value  = buying pressure at bid

  - Add dynamic_stop_loss(entry_price, atr, regime):
      Trending regime:  stop = entry - 1.5 * ATR  (tight)
      Choppy regime:    stop = entry - 2.5 * ATR  (wide)
      High volatility:  stop = entry - 3.0 * ATR  (very wide)

  - Add cooldown_counter:
      After a stop-loss hit, suppress new signals for N bars (default N=3)
      Prevents overtrading during choppy / whipsaw conditions

      Stacking ensemble score 0.20   (Step 9)
      Quantum signals score   0.10   (Step 10)

    final_conviction = sum(weight_i * score_i for all i)

  Kelly Criterion position sizing:
    f* = (p * b - q) / b

    Where:
      p = historical win rate
      q = 1 - p  (loss rate)
      b = avg_win / avg_loss  (reward-to-risk ratio)
      f* = fraction of capital to risk

    Implementation rules:
      Use half-Kelly:  position_size = 0.5 * f* * total_capital
      Hard cap: max 25% of capital in any single trade
      Min threshold: only trade if f* > 0.02 (avoid tiny edge bets)

  generate_trade_signal(conviction_threshold=0.75):
    Returns dict:
      {
        "action":      "BUY" | "SELL" | "HOLD",
        "conviction":  float (0.0 to 1.0),
        "position_sz": float (dollar amount),
        "entry":       float,
        "stop_loss":   float,
        "take_profit": float,
        "reward_risk": float
      }
    Only fires if conviction > threshold AND regime is not CHOPPY
